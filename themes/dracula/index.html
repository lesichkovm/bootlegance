Dracula

A high-contrast, vibrant palette of purples, pinks and greens — the most ported theme in the Linux world, rebuilt for Bootstrap 5.

Palette

Dracula is eleven colours: three surfaces, a foreground, a comment grey and seven vibrant accents. Two modes only — dark (below) and light via data-bs-theme="light". The softened counterpart lives in its own theme.

Neon layer

Toggle data-neon to add a soft accent glow to primary buttons, cards, focus rings and anything marked .dr-glow.

Prefer the softer take? → Dracula Soft

Code block

// main.js
const theme = 'dracula';
const accent = { purple: '#bd93f9', pink: '#ff79c6' };

function apply(name) {
    return { theme, accent: accent[name] ?? 0 };
}
